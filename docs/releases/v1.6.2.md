# 黑猫记账 v1.6.2

本次针对「设置页呈现方式」和「明细表格」做体验优化。

## 1. 设置整合进主页面

- 设置不再是从顶部下拉的浮层，而是**作为主页面里的一个普通版块**（和明细、统计等一样在页面流中），点击右上角齿轮即在页面内展开。
- 进入设置时**自动隐藏「今日统计」卡片**，页面更聚焦；底部 Tab 取消高亮，点任意 Tab 或右上角 ✕ 即可返回原版块。
- 移除了整屏遮罩层，不再有浮层压暗、也不再"突兀"。
- 设置内的所有功能（分类事项配置、数据备份/导入、应用更新）保持不变。

## 2. 明细表格列宽优化

- 表格改为固定列宽布局，**日期强制单行显示**（"2026-10-27" 不再折成两行）。
- **事项列明显收窄**，过长时以省略号截断；点击该单元格弹出**详情浮窗**，显示完整事项、金额、分类、日期、时间、类型。
- 详情浮窗内新增「编辑 / 删除」按钮，避免窄屏下右侧操作列不好点。
- 列宽总量控制在可视区内，不再出现横向溢出导致删除按钮被挤出屏幕。

## 其它

- 无数据结构变更，升级不影响已有账目。
